# 📁 UT6 — Estructuras de datos y acceso a bases de datos

Unidad de trabajo del módulo profesional de **Programación** (Curso 2025–26).

---

## Distribución del directorio

```
UT6/
├── Recursos/          # Ficheros de apoyo para realizar los ejercicios
└── Soluciones/        # Código fuente Java con la solución de cada ejercicio
```

### 📂 Recursos

Contiene todos los ficheros auxiliares necesarios para poder ejecutar los ejercicios: ficheros CSV y JSON de entrada, scripts SQL de creación y población de bases de datos, clases de dominio Java y generadores de ficheros binarios `.dat`. Está organizado con la misma estructura de bloques y subbloques que el cuaderno de actividades.

→ Consultar `Recursos/README.md` para el detalle completo de cada subbloque.

### 📂 Soluciones

Contiene los ficheros `.java` con la solución de cada uno de los ejercicios propuestos en el cuaderno de actividades. Están organizados por bloque y subbloque siguiendo el mismo esquema de nomenclatura del enunciado.

→ Consultar `Soluciones/README.md` para el detalle completo de cada subbloque.

## Tecnologías y herramientas

- **Lenguaje:** Java (JDK 17+)
- **IDE:** NetBeans
- **Base de datos:** MySQL 8
- **Librerías externas:** `org.json` (para manejo de ficheros JSON)
- **JDBC:** `mysql-connector-j`
